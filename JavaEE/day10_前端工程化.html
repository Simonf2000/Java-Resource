        class Person{

            //get set方法

                console.log('正在给age赋值，值是'+a);
                this.#age=a
            }

                console.log('正在获取a的值');

            //实例方法
            eat=function(){
                console.log(this.name+"在吃饭"+this.#age);

            static sleep=function(){
                console.log(this.id+"在睡觉");
            }

            constructor(i,n,a){
                console.log('构造方法');
                this.id=i;
                this.name=n;
                this.#age=a
            }

            
        }

    # 3.Nodejs

    # 3.1 安装Nodejs

    • 双击安装即可

    # 3.2 npm

    • 配置下载地址

      • npm config set registry https://registry.npmmirror.com 或 https://mirrors.tencent.com/npm/
      • npm config get registry

    • 配置本地库地址

      • npm config set prefix "D:\GlobalNodeModules"
      • npm config get prefix

    • 升级npm

      • npm install -g npm@9.6.6

    # 3.3 npm常用命令

    • npm init 初始化

      • -y 对所有提问回答yes

    • npm install 产品名字@版本

      • 不指定版本下载最新的
      • -g 下载到本地库
      • npm install 安装已经在package.json中记录的第三方工具

    • npm uninstall 产品名字

    • npm update 产品名字

      • 更新产品

    • npm ls

      • 查看本项目的依赖

    • npm list -g

      • 查看本地库的依赖

    • npm run 运行内容的名字

      • 后期使用dev的脚本，启动前端服务器

    # 5. Vite

    • npm create vite

      • 创建Vite+vue3的项目

    • cd 项目内

    • npm install

      • 安装依赖

    • npm run dev

      • 自动化构建+部署
      • ctrl+c结束服务

    # 5.1 Vite项目的目录结构

    • day10_vite 项目名

      • node_modules 依赖所在的目录

      • src 源代码

        • assets

          • 静态资源

        • components

          • 组件(vue文件)

        • pages

          • 组件(vue文件)

        • routers

          • 路由文件(js文件)

        • stores

          • 共享数据的

        • App.vue （核心组件）

        • main.js (核心js文件)

        • style.css

      • index.html 首页

      • package.json 项目信息文件

      • vite.config.js vite项目的配置文件

        • 端口号
        • 代理主机
        • ...

    # 5.2 vite项目运行原理

    • 只有一个页面(index.html)
      • index.html网页内引入main.js
      • main.js进行Vue挂载，引入App.vue
    • 将App.vue的内容挂载在index.html网页上

    # 5.3 组件

    • 组件文件是后缀为.vue的文件

      • html+css+js

    • xxx.vue

      • script标签(编写js代码)
      • template标签(编写html代码)
      • style标签(编写css代码)
