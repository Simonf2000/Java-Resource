# 2.日程管理的增删改查

- 见项目

## 2.1 新增需求

- 点击新增日程按钮，触发单击事件，调用一个函数
- 发送异步请求到服务器进行默认数据的添加
  - 将当前登录人的uid传过去

- 给前台响应，前台要展示日程信息列表(包括刚刚新增的数据)
  - 在发送一次查询当前用户日程信息的请求

## 2.2 修改的需求

- 点击保存修改的按钮，触发单击事件，调用一个函数
- 发送异步请求到服务器进行数据修改
  - 将当前这一条数据传递过去(sid,uid,新的title,新的completed)

- 给前台响应，前台要展示日程信息列表(包括刚刚修改的数据)
  - 在发送一次查询当前用户日程信息的请求

## 2.3 删除的需求

- 点击删除，触发单击事件，调用一个函数
- 发送异步请求到服务器进行数据删除
  - 传递sid过去

- 给前台响应，前台要展示日程信息列表(包括刚刚修改的数据)

- 在发送一次查询当前用户日程信息的请求
